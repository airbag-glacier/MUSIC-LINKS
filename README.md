A centralized, minimalist landing page routing listeners to my official music releases across various streaming platforms and digital stores. 

## 🎧 About

As an independent musician, maintaining a single, clean point of contact is essential for connecting with listeners. This repository contains the source code for my digital music hub, designed with a clean, editorial aesthetic to ensure the focus remains purely on the music. 

This page serves as the gateway to my acoustic-driven tracks and digital releases, making it easy for listeners to find singles like **Far Away**, **Agos**, and **absurdism** wherever they prefer to stream.
